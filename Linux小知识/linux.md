##### 将一个命令的输出直接在vim中显示

```shell
strace -f gcc -o hello hello.c 2>&1 | vim -
```

##### 不要在vim中使用鼠标滚轮

```shell
#禁用鼠标功能
:set mouse=
```

##### 在vim中使用grep来过滤内容

```shell
:%!grep -v -e '-1'
#:%!：将整个文件的内容通过管道传递给外部命令。
#grep -v -e '-1'：grep -v 会反转匹配，即过滤掉包含 -1 的所有行
#-e 就代表进行匹配
```

`argv[0]` 是这个数组的第一个元素，它指向一个字符串，该字符串是程序的名称或路径。在大多数操作系统上，如果你从命令行或终端启动程序，`argv[0]` 将包含你用来启动程序的命令或脚本的名称

##### 编译优化三板斧

- 函数内连：将函数调用替换为函数体本身的内容。
- 常量传播：在编译时计算常量表达式的值并替换。
- 死代码消除：删除永远不会执行到的代码。
